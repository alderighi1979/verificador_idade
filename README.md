# Verificador de Idade

Este projeto é um simples verificador de idade que calcula a idade de uma pessoa com base no ano de nascimento fornecido e exibe uma imagem correspondente ao grupo etário e ao gênero selecionado.

## Tecnologias Utilizadas

- HTML
- CSS
- JavaScript

## Estrutura do Projeto

O projeto é composto por três arquivos principais:

1. **index.html**: O arquivo HTML que contém a estrutura da página.
2. **main.css**: O arquivo CSS que estiliza a página.
3. **main.js**: O arquivo JavaScript que contém a lógica para calcular a idade e exibir o resultado.

## Como Usar

1. **Clone o repositório** ou faça o download dos arquivos.
2. **Abra o arquivo `index.html`** em um navegador da web.
3. **Preencha o campo "Ano de Nascimento"** com o ano desejado.
4. **Selecione o gênero** (Masculino ou Feminino).
5. **Clique no botão "Verificar"** para calcular a idade e ver o resultado.

## Funcionamento

- O usuário insere o ano de nascimento e seleciona o gênero.
- Ao clicar no botão "Verificar", a função `verificar()` é chamada.
- A função calcula a idade com base no ano atual e no ano de nascimento.
- Dependendo da idade e do gênero selecionado, uma imagem correspondente é exibida junto com uma mensagem informando a idade e o gênero.

## Estilo

O estilo da página é definido no arquivo `main.css`, que inclui:

- Um fundo azul claro para o corpo da página.
- Estilo centralizado e colorido para o cabeçalho e rodapé.
- Um cartão branco com bordas arredondadas e sombra para a seção principal.
